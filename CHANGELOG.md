# Changelog

## 0.1.3

- Refresh the npm listing with the project cover, clearer package description and direct GitHub links.
- Use absolute documentation and screenshot URLs so they also resolve on package catalogs.
- Update installation examples to this documentation release; device-control runtime is unchanged.

## 0.1.2

- Prepare npm distribution with the standard Homebridge plugin search and update path.
- Update English and Italian installation guides while retaining GitHub archives.
- Ventilation control behavior is unchanged from 0.1.1.

## 0.1.1

- Reworked the project page with a concise overview, compatibility evidence, navigation and a real Homebridge settings screenshot using example data.
- Added Italian documentation and dedicated installation, configuration, troubleshooting and contribution guides.
- Added issue forms for bug reports and hardware compatibility reports.
- Replaced room-specific public examples with generic device names and stable IDs.
- Added service tests against HAP-NodeJS 0.12.3 (used by Homebridge 1.8.5) on Node.js 22.
- Added the public display name to package metadata and included the documentation in the installable archive.
- Ventilation control behavior is unchanged from 0.1.0.

## 0.1.0

- Initial local Wi-Fi integration for PRANA units with firmware 49+.
- Apple Home fan, airflow, mode switches, temperatures, humidity and equivalent CO2.
- Stable accessory identities, configurable labels, automatic reconnection and serialized commands.
- No runtime dependencies, no cloud credentials and no startup setting changes.
